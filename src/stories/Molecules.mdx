# Molecules

Combinações de átomos com um propósito (ex.: `FormField` = rótulo + campo + erro).

| Molécula | Status | Tarefa |
|---|---|---|
| FormField, MoneyField, SearchField | prontos | SHP-48 |
| TabItem, FilterChip, SegmentedControl | prontos | SHP-49 |
| StatCard, KeyValueRow | prontos | SHP-50 |
| Toast, InlineAlert | prontos | SHP-51 |
| TapeProgress, BarRow | prontos | SHP-52 |
| ProductLine, Deadline | prontos | SHP-53 |
| EmptyState + ilustrações | prontos | SHP-54 |
| NavItem | pronto | SHP-55 |
| StepIndicator | pronto | SHP-55 |

Cada molécula nova ganha story aqui na mesma tarefa.
